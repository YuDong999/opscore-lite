## 结论与补差优先级（建议顺序）

**P0（对齐常用体验，工作量小）**
1. 数据页表格分页可调页大小 + 选中数统计（GoNavi/dbx 都有）
2. 表右键补危险维护组：清空表/删除表（走写锁护栏+统一确认）
3. 表信息抽屉补 索引/外键/触发器 页签（后端 /describe 已含索引，外键触发器需接口）

**P1（对齐主链路）**
4. 同步：源/目标一键交换 + 目标侧表名统一大小写选项 + 完成刷新目标树
5. 网格右键补：置NULL/转置/克隆行为新行/多格式复制（JSON/TSV/Markdown）
6. 导出粒度：当前页/全部结果（后端已支持 sql 参数，加页级 SQL 即可）

**P2（锦上添花/重后端）**
7. 库内函数/触发器/事件/序列分组（后端枚举接口，dbx 与 GoNavi 均有）
8. 表展开出 列/索引/外键 子目录（表级懒加载）
9. 批量编辑（条件范围 UPDATE 生成，配合写锁）
10. 表概览库级页（复用 /table-counts + 存储统计接口）
11. 筛选构建器（多规则 AND/OR + 实时 SQL 预览）
