# D 型特性映射表 — dbx vs opscore-lite（数据库管理）

图例: ✅ 有 · ⚠️ 部分(有后端缺前端或有雏形) · ❌ 缺 · 🚫 决定不做(AI等)
后端缺口列 = 我们 Go 侧需要新增的接口/逻辑。

## 侧栏树
| 特性 | dbx | opscore | 后端缺口 |
|---|---|---|---|
| 懒加载树 连接→库→schema→分组→对象 | ✅ | ⚠️ 缺 schema 层(库下直接平铺对象) | metadata 返回对象 schema, 前端加一层 |
| 分组(表/视图/存储过程/函数/序列/触发器) | ✅ | ⚠️ 仅表/视图 | routines 接口(SHOW PROCEDURE/FUNCTION/TRIGGERS) |
| 对象搜索(侧栏过滤) | ✅ | ✅ | — |
| 置顶表 | ✅ | ✅ | — |
| 行内重命名(F2) | ✅ | ❌ | RENAME 走 /query 拦截链 |
| 拖拽排序连接 | ✅ | ❌ | config.group/order 字段 |
| 连接分组+移动到分组 | ✅ | ❌ | config.group 字段已有 |
| 多选批量操作 | ✅ | ❌ | — |
| 连接健康/断开 | ✅ | ⚠️ 测试连接有, 无显式断开 | /connections/{id}/close |
| 导入导出连接配置 | ✅ | ✅ | — |

## 数据网格
| 特性 | dbx | opscore | 后端缺口 |
|---|---|---|---|
| 分页/排序 | ✅ | ✅ | — |

| 列筛选控件(WHERE构建) | ✅ | ❌ | /data 已支持 where 参数 |
| 右键过滤(LIKE) | ✅ | ❌ | 同上 |
| 单元格详情弹层 | ✅ | ❌ | 纯前端 |

| 图表 | ✅ vue-echarts | ❌ | 纯前端(echarts) |
| 完整单元格换行详情 | ✅ | ❌ | 纯前端 |
