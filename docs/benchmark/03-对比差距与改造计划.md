# opscore-lite 对比差距与改造计划

> 对比基准：`01-GoNavi-功能与架构清单.md`、`02-dbx-功能与架构清单.md`。
> 现状代码：`web/src/components/DatabaseManager/*`、`web/src/modules/DatabaseManagerModule.tsx`、`internal/dbmanager/*`。

## 1. 现状 vs 基准（逐项）

| # | 能力 | GoNavi/dbx | opscore-lite 现状 | 差距 | 优先级 |
|---|---|---|---|---|---|
| 1 | 对象侧栏 | 懒加载树：连接→库→(schema)→分组[表/视图/函数/触发器/事件]→对象，行数徽标/在线点/搜索/筛选/置顶 | CascadeSelector 两个平铺下拉（库/表分离），无树 | **结构性差距** | P0 |
| 2 | 布局骨架 | 树 + 多标签工作台 + (AI 面板)；每标签绑定连接·库上下文 | 左侧栏 + 右侧固定 tab（查询/表结构/同步/审计），无标签页工作台 | 大 | P0 |
| 3 | 表数据浏览 | 双击表即开数据网格（类型列头/筛选/分页/编辑） | 无。必须手动写 SELECT | **核心功能缺失** | P0 |
| 4 | 右上角重复按钮 | — | module-head「+ 新建连接」与面板内重复 | 小 | P0 |
| 5 | 查询执行摘要 | 多语句逐条结果（语句/类型/返回行/影响行/耗时/成败） | 单结果集，多语句只回最后 | 中 | P1 |
| 6 | 右键可视化操作 | 查看 DDL/复制为 INSERT/重命名/备份/置顶 | 无任何右键菜单 | 大 | P1 |
| 7 | 列头交互 | 每列筛选/排序控件、自动列宽、单元格详情 | 仅表头排序+复制 | 中 | P1 |
| 8 | 命令面板 | Ctrl+K 搜连接/表/动作（GoNavi 搜索表、连接、动作；dbx quick-open） | 无 | 中 | P1 |
| 9 | 连接向导 | 3 步式+连接串解析/生成+通配库范围+分组管理 | 两步式（选引擎→填表单），已有 SSH/代理/SSL | 中 | P2 |
| 10 | 表结构设计器 | 可视化改列/索引 + 变更 SQL 预览 | 只读 DocPanel | 大 | P2 |
| 11 | ER 图 / 血缘 / 执行计划 | 有 | 无 | 大 | P3 |
| 12 | 导入（CSV/Excel）| 有 | 无（仅导出） | 中 | P2 |
| 13 | 库内搜索 | FindInDatabase/数据库搜索 | 无 | 中 | P2 |
| 14 | SQL 文件执行/外部 SQL 目录 | 有 | 无 | 中 | P3 |
| 15 | AI 助手面板 | 对话式（GoNavi/dbx 均有） | 无 | 大 | P3 |
| 16 | 连接分组/置顶/最近 | 有 | 无 | 小 | P2 |
| 17 | 跨库同步 | DataSyncWorkbench | ✅ 已实现（5 模式+计划预览+进度） | 领先项保持 | — |
| 18 | 审计/写锁/风险拦截 | GoNavi 有审计 | ✅ 已实现且有解锁倒计时 | 领先项保持 | — |
| 19 | 引擎覆盖 | 33/90+ | 34（元数据级），可连=12 内置+已装 agent | 持平(GoNavi) | — |

## 2. 改造计划（分阶段，本仓库落地）

### P0 本轮必做（布局骨架闭环）
1. **ConnectionTree 树状侧栏**替换 CascadeSelector：
   - 层级 `连接(在线点) → 库 → 表/视图分组 → 对象`，懒加载（点开才查），行数徽标（表概览接口已有行数能力则用，无则省略）
   - 节点搜索框（前端过滤）
   - 单击表 = 打开「数据浏览」标签；双击库 = 设为查询上下文
   - 后端：`/api/dbmanager/metadata?type=databases|tables` 已有；新增 `/api/dbmanager/data`（分页读表数据：SELECT * ... LIMIT/OFFSET + 总数）→ 支撑 #3
2. **标签页工作台**（TabManager 简化版）：
   - tab 类型：`data:connId.db.table`、`query:connId[.db]`、`doc:connId.db.table`、`sync`、`audit`
   - TABLE 标签 = DataPanel（分页网格 + 列头类型 + 工具条：刷新/翻页/每页行数/导出）
   - 右键菜单 v1：表 → 查看数据/新建查询(带 FROM)/查看 DDL/复制表名
3. **去掉 module-head 的「+ 新建连接」**（保留面板内入口），概览页保留大按钮
4. DataPanel 复用 DataGrid（排序/复制/导出已具备），补分页与总数

### P1（交互增强）
5. 查询多语句执行摘要：后端 `/query` 返回 `statements[]`（复用 gonavi QueryMultiContextWithMessages）
6. 右键菜单补全：复制结构 DDL、复制全表为 INSERT（后端已有 sync 的转义器可复用）、置顶表(localStorage)
7. 列头筛选控件（WHERE 片段下发 DataPanel）、单元格详情弹层
8. Ctrl+K 命令面板：连接/表/动作（React 简版，无依赖）

### P2（功能补齐）
9. 连接向导加连接串解析/生成 + 库显示范围通配 + 连接分组
10. 表设计器 v1（列编辑 + 生成 ALTER 预览，走写锁拦截链）
11. CSV 导入（DataPanel → POST /import，复用批量 INSERT 通道）
12. 库内搜索（information_schema 模糊查 + 跳转）

### P3（差异化/重活）
13. ER 图（mermaid erDiagram，前端已有依赖则直接用）
14. AI 面板（接 OpenAI 兼容端点，上下文=当前表结构）
15. SQL 文件执行工作台

## 3. 后端新增接口（P0/P1）

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/dbmanager/data` | GET | `?id&database&table&page&pageSize&orderBy&orderDir&where` → `{columns, rows, total, page}`（列名白名单校验防注入） |
| `/api/dbmanager/table-meta` | GET | `?id&database&table` → 行数/大小/创建时间（复用 gonavi GetTableRowCounts/GetTableStorageStats 可用部分） |
| `/api/dbmanager/query` 扩展 | POST | 多语句时返回 `statements:[{sql,type,rows,affected,durationMs,error}]` |

安全约束延续 ADR-003：data 读取只读；写操作仍走风险拦截链。
