# 跨库同步 · 层级组合表（设计基准）

> 结论先行：源端、目标端各恒定两栏。**范围栏**的标签与可选性由该侧引擎的命名层级决定
> （能力探测驱动，无引擎硬编码）；**表栏**跨引擎同构。入口层级（库/模式/表右键）
> 只影响源端的预置与固定，目标端永远自由可选。

## 0. 引擎命名层级分类（sync/typemap.go 注册表 + /schemas 能力探测）

| 层级 | 引擎族 | 真实可选的"范围" | 库的真实性 |
|---|---|---|---|
| 两级 库→表 | mysql, mariadb, goldendb | 库 | 真选择(跨库查询/写入有效) |
| 三级 库→模式→表 | postgres, opengauss, kingbase, highgo, vastbase, gaussdb | 模式 | 假层级(驱动只查连接库) → 库=连接库, 仅作上下文 |
| 三级变体 连接→模式→对象(无库层) | oracle 族(未接入) | 模式 | 无库层, 接入时扩展无库结构 |
| 三级变体 库→模式→表(SQL Server 型) | sqlserver(未接入) | 模式 | 同 PG 族处理 |

## 表A · 源端两行（入口层级 × 源引擎层级 = 6 种渲染）

| 入口 | 源引擎 | 行1·源连接 | 行1·范围栏 | 行1·表栏 |
|---|---|---|---|---|
| 面板进入 | 两级 | 可选(默认当前连接) | **库·可选**(库列表) | 可选(整库表) |
| 面板进入 | 三级 | 可选(默认当前连接) | **模式·可选**(默认=全部模式) | 可选(全部模式表) |
| 库级右键 | 两级 | 可选 | **库·固定**(该库) | 可选(该库表) |
| 库级右键 | 三级 | 可选 | **模式·可选**(默认=全部模式=整库) + dim"库=连接库" | 可选(全部模式表) |
| 模式级右键 | 三级 | 可选 | **模式·固定**(该模式) + dim"库=连接库" | 可选(该模式表) |
| 表级右键 | 两级 | 可选 | **库·固定**(表所属库) | 该表**锁定**(标注"入口表") + 可追加其他表 |
| 表级右键 | 三级 | 可选 | **模式·固定**(表所属模式) + dim"库=连接库" | 该表**锁定** + 可追加 |

- 全部"固定"都可解除：**更换源连接即清除入口预设**，横幅同步消失。
- 全部"固定"都有 `· 固定` 标注 + 半透明；表锁定 checkbox 禁用并参与全选/清空/反选的保护。

## 表B · 目标端两行（目标引擎层级 = 2 种渲染；目标端无入口预设，永远自由）

| 目标引擎 | 行2·目标连接 | 行2·范围栏 |
|---|---|---|
| 两级 | 可选(禁选源连接) | **库·可选**(库列表) |
| 三级 | 可选(禁选源连接) | **模式·可选**(默认 public→首个) + dim"库=连接库, 表建在所选模式下" |

## 表C · 源×目标 4 组合全览（2×2，每格给出两行的最终形态）

| 组合 | 源端两栏 | 目标端两栏 | 后端请求 | 验证 |
|---|---|---|---|---|
| 两级→两级 | 库(可选/固定) + 表 | 库(可选) + 表 | sourceDb + targetDb | MySQL→MySQL 老路径 ✓ |
| 两级→三级 | 库(可选/固定) + 表 | 模式(可选, 库=连接库) + 表 | sourceDb + targetDb(连接库) + targetSchema | MySQL→PG `s2.users_t2` 5 行 ✓ |
| 三级→两级 | 模式(可选/固定, 库=连接库) + 表 | 库(可选) + 表 | sourceDb(连接库) + 源表限定名 + targetDb | PG→MySQL `public.users_copy` 5 行 ✓ |
| 三级→三级 | 模式(可选/固定, 库=连接库) + 表 | 模式(可选, 库=连接库) + 表 | sourceDb + targetDb + targetSchema | PG→PG `pg2.users_pg2pg` 5 行 ✓ |

约束：源连接 ≠ 目标连接(防自环，与层级无关)；同引擎族异连接(A PG→B PG)合法已实测。

## 表D · 层级表达式的落库形态（后端契约, sync.SyncRequest）

| 端 | 两级引擎 | 三级引擎 |
|---|---|---|
| 源 | `sourceDb=所选库`, 表名=裸名 | `sourceDb=连接库`, 表名=`schema.table` 限定名(执行器 splitQualified 拆分) |
| 目标 | `targetDb=所选库`, DDL 直接 `db.table` | `targetDb=连接库`, `targetSchema=所选模式`, DDL `"schema"."table"`; 未传 targetSchema 时按方言回落(MySQL=库, PG=search_path) |
